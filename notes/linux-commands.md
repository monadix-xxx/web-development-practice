# Linux: компактная демонстрация для отчёта

Для отчёта не нужно помещать в один терминал вывод десятков отдельных команд. Один скрипт выполняет и показывает ограниченный набор файловых операций и работу с процессом:

```bash
nix develop ./nix/linux -c bash scripts/linux-proof.sh
```

Вывод занимает около 8 строк и содержит:

- название Linux-системы;
- текущий каталог;
- создание, копирование и переименование файлов;
- `find`, `grep`, `wc`;
- запуск фонового `sleep`, его PID/состояние и завершение через `kill`.

Этого достаточно как компактного подтверждения локальной практики; в тексте отчёта перечислены и объяснены остальные изученные команды.
